# Aegis — AI Security Assistant

## 1. Overview

Aegis is the security assistant component of Extension AI Guard.

Aegis provides users with onboarding guidance, browser-extension security information, network traffic analysis guidance, safe testing information, detection explanations, and security alert interpretation.

The current Phase 4 implementation uses deterministic backend responses. It does not depend on an external large language model.

The architecture is designed so that Aegis can later consume detection results and security events generated by the Extension AI Guard detection pipeline.

---

## 2. Objectives

Aegis is designed to:

1. Guide first-time users through the Extension AI Guard platform.
2. Maintain onboarding progress for each authenticated user.
3. Support returning users after onboarding completion.
4. Provide basic browser-extension security guidance.
5. Explain network traffic analysis concepts.
6. Explain malicious-extension behavior.
7. Explain security alerts in human-readable language.
8. Provide safe security-testing guidance.
9. Enforce authenticated access to protected Aegis functionality.
10. Provide a foundation for future AI-assisted security analysis.
